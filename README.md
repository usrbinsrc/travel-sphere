# Travel Sphere

A clean, responsive website designed for a modern travel agency. This project was built to practice creating multi-page layouts, structuring content, and applying responsive web design principles.

🌐 [Live Preview](https://travelsphereagency.vercel.app/)

## 🚀 Features

* **Home:** An inviting landing page featuring a hero section and featured travel highlights.
* **Destinations:** A gallery showcasing various travel locations and vacation packages.
* **About Us:** Information regarding the agency's mission and history.
* **Contact:** A user-friendly page with a contact form for inquiries.
* **Authentication:** Clean, functional layouts for user Login and Sign Up pages.

## 🛠️ Technologies Used

* **HTML5:** For semantic web structure.
* **CSS3:** For custom styling, typography, and color themes.
* **Bootstrap:** For a responsive layout grid and pre-styled UI components.

## 💡 Purpose

This project is a static front-end website created purely for educational purposes. It serves as a practical exercise to strengthen foundational frontend development skills and master responsive design frameworks.
